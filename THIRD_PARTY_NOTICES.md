# Third-party notices

The AgentProof runtime currently has no third-party Go module dependencies; it uses the Go standard library.

Repository automation references official GitHub Actions by immutable commit SHA. Those Actions execute from their own repositories and are not redistributed in AgentProof release archives. Their respective license and notice files remain available in those repositories.

The canonical evidence-manifest foundation integrated into this project was supplied as part of the AgentProof project source and is covered by this repository's MIT License.
